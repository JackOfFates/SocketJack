0.3.6
- Keeps Visual Studio Copilot streams alive during silent local-model reasoning and tool phases.
- Retries a no-visible-text completion as a bounded, no-tools final-answer pass instead of closing with a bridge fallback.
- Raises the Visual Studio tool-work timeout floor to 20 minutes for long repository analysis tasks.

0.3.5
- Validates the saved JackLLM Workstation session before advertising the Copilot bridge as healthy.
- Replaces a running bridge when its non-secret token fingerprint no longer matches the current encrypted Workstation sign-in.
- Honors Remember sign-in with a 30-day Workstation token and restores the configured bridge immediately after re-authentication.

0.3.4
- Treats a local bridge health-check timeout as an absent bridge so the supervisor proceeds to launch it instead of aborting the recovery cycle.

0.3.3
- Records a non-secret supervisor status under the JackLLM Visual Studio local-data folder so bridge startup failures can be diagnosed without exposing tokens.

0.3.2
- Starts the authenticated bridge from the extension initialization callback as well as service registration.
- Keeps a lightweight supervisor active so a saved Workstation login or a stopped bridge is recovered without reopening the SocketJack tool window.

0.3.1
- Loads automatically when a solution opens so the configured Copilot bridge is available before the first chat request.
- Prevents the startup supervisor from launching an unauthenticated bridge before a saved JackLLM Workstation sign-in exists.
- Requires a matching bridge to report authenticated upstream routing before Configure reuses it.

0.3.0
- Replaces hosted login and browser authentication with sign-in against the local JackLLM Workstation account database.
- Protects the saved local Workstation token with Windows user-scoped encryption.
- Restricts model discovery, Copilot configuration, MCP setup, and Session Sync to JackLLM Workstation on 127.0.0.1:11436.
- Removes authorization headers and remote endpoint overrides from local Session Sync.
