# heirowLLM Workstation for Visual Studio

Connect Visual Studio Copilot to models running in heirowLLM Workstation on the same PC.

## Features

- Discover models from `http://127.0.0.1:11436`.
- Configure Visual Studio Copilot BYOM for the selected local model.
- Configure the packaged MCP bridge for local tools and solution context.
- Sync solution session files through the local heirowLLM Workstation API.
- Authenticate only against the heirowLLM Workstation account database on this PC.
- Operate without a hosted account, remote server directory, or cloud inference.

## Requirement

heirowLLM Workstation must be running locally, and you must sign in with an account created in that Workstation, before configuration or Session Sync can be used.
